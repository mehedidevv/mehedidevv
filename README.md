## 🎯 About Me & Engineering Philosophy

I am a **Software Engineer in the making**, focused on crafting high-performance cross-platform mobile apps and scalable backend services.

* **Mobile Application Development:** Building reactive, high-quality mobile applications with **Flutter & Dart** and **Native Android (Kotlin/Java)**. I prioritize clean state management, responsive UI/UX, modular MVVM architecture, and offline-first data caching.
* **Backend Engineering:** Engineering robust backend microservices and RESTful APIs using **Java & Spring Boot**. I focus on scalable API design, relational database modeling, security, and core system design principles.
* **Problem Solving & Algorithms:** Actively sharpening core computer science fundamentals, data structures, and algorithmic efficiency using **C++**.
* **Software Principles:** Strong commitment to **Clean Code**, SOLID design principles, maintainable software architecture, and understanding low-level framework mechanisms.
